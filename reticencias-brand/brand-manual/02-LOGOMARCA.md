# 2. Sistema de Logomarca

## 2.1 Conceito Visual

A logomarca do **reticências** é construída em torno do símbolo dos três pontos (...), reimaginado de forma contemporânea e significativa para o contexto de saúde mental.

---

## 2.2 Variações do Símbolo (10 Versões)

### Versão 1: Três Círculos Progressivos
Três círculos que aumentam gradualmente de tamanho, representando crescimento pessoal.
- **Significado**: Evolução e progresso
- **Uso**: Ícone principal do app, favicon
- **Tamanhos**: 16x16px a 1024x1024px

### Versão 2: Pontos em Trajetória Ascendente
Três pontos dispostos em diagonal ascendente, simbolizando movimento positivo.
- **Significado**: Superação e esperança
- **Uso**: Splash screen, tela de carregamento
- **Tamanhos**: 64x64px a 512x512px

### Versão 3: Círculos Interconectados
Três círculos que se sobrepõem sutilmente, criando áreas de intersecção.
- **Significado**: Conexão entre pensamentos, emoções e ações
- **Uso**: Materiais educativos, blog
- **Tamanhos**: 128x128px a 1024x1024px

### Versão 4: Pontos com Respiração
Três círculos com linhas curvas suaves emanando, sugerindo respiração.
- **Significado**: Mindfulness e técnicas de respiração
- **Uso**: Seção de exercícios de respiração
- **Tamanhos**: 256x256px a 512x512px

### Versão 5: Minimalista Linear
Três pontos simples e limpos em linha horizontal.
- **Significado**: Simplicidade e clareza
- **Uso**: Versão reduzida, contextos pequenos
- **Tamanhos**: 16x16px a 128x128px

### Versão 6: Orgânico Natural
Três formas circulares com bordas suaves e orgânicas, lembrando pedras ou gotas.
- **Significado**: Naturalidade e fluidez emocional
- **Uso**: Materiais impressos, merchandising
- **Tamanhos**: 256x256px a 1024x1024px

### Versão 7: Pontos em Onda
Três pontos dispostos seguindo uma curva suave, como uma onda.
- **Significado**: Altos e baixos da jornada emocional
- **Uso**: Gráficos de humor, visualização de dados
- **Tamanhos**: 128x128px a 512x512px

### Versão 8: Círculos Concêntricos
Cada ponto é formado por círculos concêntricos, criando profundidade.
- **Significado**: Camadas da consciência e autoconhecimento
- **Uso**: Seção de reflexões profundas
- **Tamanhos**: 256x256px a 1024x1024px

### Versão 9: Pontos com Gradiente
Três círculos com gradiente sutil de uma cor para outra.
- **Significado**: Transição e transformação gradual
- **Uso**: Telas de transição, animações
- **Tamanhos**: 128x128px a 512x512px

### Versão 10: Pontos Vazados
Três círculos com centro transparente, criando anéis.
- **Significado**: Espaço interior e introspecção
- **Uso**: Versão alternativa para fundos complexos
- **Tamanhos**: 64x64px a 512x512px

## 2.3 Composições de Logomarca

### 2.3.1 Versões Horizontais (5 variações)

**H1 - Principal Extendida**
```
[Símbolo V1] reticências
                      saúde mental
```
- Símbolo à esquerda + nome + tagline
- Uso: Cabeçalhos de site, materiais oficiais
- Proporção: 4:1

**H2 - Compacta**
```
[Símbolo V5] reticências
```
- Símbolo + nome apenas
- Uso: Menu de navegação, assinaturas
- Proporção: 3:1

**H3 - Simétrica**
```
[Símbolo V3] ... reticências ... [Símbolo V3]
```
- Símbolo em ambos os lados
- Uso: Certificados, documentos oficiais
- Proporção: 5:1

**H4 - Minimalista**
```
... reticências
```
- Pontos tipográficos + nome
- Uso: Textos corridos, rodapés
- Proporção: 4:1

**H5 - Dividida**
```
[Símbolo V1] | reticências | saúde mental
```
- Com divisores verticais
- Uso: Apresentações, slides
- Proporção: 6:1

### 2.3.2 Versões Verticais (5 variações)

**V1 - Clássica Centralizada**
```
    [Símbolo V1]
    
   reticências
   
   saúde mental
```
- Todos os elementos centralizados
- Uso: Aplicativo móvel, splash screen
- Proporção: 1:2

**V2 - Compacta**
```
  [Símbolo V5]
  
 reticências
```
- Sem tagline
- Uso: Ícone de app com texto
- Proporção: 1:1.5

**V3 - Integrada**
```
reticências
     ...
saúde mental
```
- Símbolo integrado ao texto
- Uso: Posts de redes sociais
- Proporção: 1:1.8

**V4 - Empilhada**
```
[Símbolo V6]
━━━━━━━
reticências
saúde mental
```
- Com linha separadora
- Uso: Banners verticais
- Proporção: 1:2.5

**V5 - Flutuante**
```
        [Símbolo V2]
        
   reticências
```
- Símbolo em posição elevada
- Uso: Materiais promocionais
- Proporção: 1:1.6

### 2.3.3 Versões Quadradas (5 variações)

**Q1 - Ícone Puro**
```
   [Símbolo V1]
```
- Apenas o símbolo
- Uso: App icon, favicon
- Tamanho: 1024x1024px

**Q2 - Com Iniciais**
```
   [Símbolo V1]
        R
```
- Símbolo + inicial
- Uso: Avatar, perfis sociais
- Tamanho: 512x512px

**Q3 - Badge Circular**
```
  ┌─────────┐
  │[Símbolo]│
  │    r    │
  └─────────┘
```
- Em moldura circular
- Uso: Selos, certificações
- Tamanho: 256x256px

**Q4 - Composição Centralizada**
```
   reticências
   [Símbolo V1]
   saúde mental
```
- Texto acima e abaixo
- Uso: Tiles, widgets
- Tamanho: 512x512px

**Q5 - Grid Equilibrado**
```
[Símbolo V1]  reticências
              saúde mental
```
- Em layout de grid 2x2
- Uso: Publicidade quadrada
- Tamanho: 1080x1080px

## 2.4 Área de Proteção

A área de proteção mínima ao redor da logomarca deve ser equivalente à altura de um ponto do símbolo em todas as direções.

```
    ┌───────────────────────┐
    │         [x]           │
    │    ┌─────────┐        │
    │[x] │ LOGO    │ [x]    │
    │    └─────────┘        │
    │         [x]           │
    └───────────────────────┘
```

**Onde [x] = altura de um ponto do símbolo**

---

## 2.5 Tamanhos Mínimos

### Digital
- Horizontal: 120px de largura mínima
- Vertical: 80px de altura mínima
- Quadrada: 48x48px mínimo
- Favicon: 16x16px, 32x32px

### Impresso
- Horizontal: 30mm de largura mínima
- Vertical: 20mm de altura mínima
- Quadrada: 15x15mm mínimo

---

## 2.6 Versões Monocromáticas

### Para Fundos Claros
- **Preto 100%**: Uso em documentos oficiais
- **Cinza 80%**: Uso em aplicações secundárias
- **Contorno**: Versão vazada para casos especiais

### Para Fundos Escuros
- **Branco 100%**: Uso padrão em fundos escuros
- **Cinza claro 90%**: Uso em aplicações secundárias
- **Contorno**: Versão vazada para casos especiais

### Inversão de Cores
A logomarca deve funcionar tanto em modo claro quanto escuro:
- **Modo Claro**: Símbolo na cor primária, texto em cinza escuro
- **Modo Escuro**: Símbolo em gradiente suave, texto em branco

---

## 2.7 Aplicações Incorretas (Não Fazer)

❌ Distorcer as proporções  
❌ Rotacionar a logomarca  
❌ Adicionar efeitos de sombra ou brilho  
❌ Usar cores não especificadas  
❌ Recriar ou redesenhar a logomarca  
❌ Posicionar sobre fundos complexos sem área de proteção  
❌ Comprimir ou esticar verticalmente/horizontalmente  
❌ Usar com baixa resolução ou pixelizado  

---

## 2.8 Formatos de Arquivo

### Fornecidos
- **AI** (Adobe Illustrator): Arquivo fonte editável
- **EPS**: Compatibilidade universal para impressão
- **SVG**: Uso web responsivo e escalável
- **PNG**: Transparente em múltiplas resoluções (16px a 4096px)
- **PDF**: Para documentação e apresentações
- **ICO**: Para favicon e ícone do Windows

### Nomenclatura
```
reticencias-logo-[versão]-[variação]-[tamanho].[formato]
Exemplo: reticencias-logo-horizontal-h1-1200px.png
```
