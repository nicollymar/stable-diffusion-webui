# 4. Sistema de Tipografia

## 4.1 Filosofia Tipográfica

A tipografia do **reticências** foi escolhida para transmitir **acolhimento, segurança, modernidade e acessibilidade**. O sistema equilibra legibilidade ótima com personalidade suave, evitando extremos que possam causar desconforto visual.

---

## 4.2 Família Tipográfica Principal

### 4.2.1 Fonte Selecionada: **Inter**

**Justificativa da Escolha**:
- ✅ Excelente legibilidade em telas digitais (otimizada para displays)
- ✅ Humanista e acolhedora sem ser excessivamente casual
- ✅ Ampla gama de pesos (100-900) para hierarquia clara
- ✅ Suporte completo a português e caracteres especiais
- ✅ Open source e gratuita (OFL License)
- ✅ Performance otimizada com variable fonts
- ✅ Alturas-x generosas para leitura confortável

**Fonte Alternativa (Fallback)**: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif

**Download**: https://rsms.me/inter/

---

### 4.2.2 Pesos Utilizados

**Inter Thin (100)** - Não utilizado  
**Inter Extra Light (200)** - Uso decorativo apenas  
**Inter Light (300)** - Subtítulos secundários, legendas longas  
**Inter Regular (400)** - Corpo de texto, parágrafos principais  
**Inter Medium (500)** - Subtítulos, labels de formulário  
**Inter Semi Bold (600)** - Títulos secundários (H3-H6)  
**Inter Bold (700)** - Títulos principais (H1-H2), botões  
**Inter Extra Bold (800)** - Não utilizado  
**Inter Black (900)** - Uso especial em marketing apenas

## 4.4 Espaçamento e Ritmo Vertical

### 4.4.1 Margem Inferior (Margin Bottom)

**Títulos**:
- H1: 24px (1.5rem)
- H2: 20px (1.25rem)
- H3: 16px (1rem)
- H4: 14px (0.875rem)
- H5: 12px (0.75rem)
- H6: 10px (0.625rem)

**Parágrafos**:
- Body Large: 20px (1.25rem)
- Body: 16px (1rem)
- Body Small: 12px (0.75rem)

**Espaçamento entre Seções**: 48px (3rem) mobile, 64px (4rem) desktop

---

### 4.4.2 Espaçamento de Parágrafos

**Parágrafo único**: Sem espaçamento adicional  
**Entre parágrafos**: 16px (1rem)  
**Entre seções de texto**: 32px (2rem)  
**Entre módulos de conteúdo**: 48px (3rem)  

---

## 4.5 Medidas de Coluna e Legibilidade

### 4.5.1 Largura Ideal de Linha

**Corpo de texto**:
- **Mínimo**: 280px (evitar quebras excessivas)
- **Ideal**: 600-700px (55-75 caracteres por linha)
- **Máximo**: 800px (evitar linhas muito longas)

**Títulos**:
- **Máximo**: 900px (permitir títulos mais largos)

**Conteúdo Centralizado**:
- **Máximo**: 640px (para leitura confortável)

---

### 4.5.2 Alinhamento

**Títulos**: À esquerda (nunca justificado)  
**Corpo de texto**: À esquerda (nunca justificado para evitar espaçamento irregular)  
**Citações**: À esquerda com margem/padding  
**CTAs e botões**: Centro quando sozinhos, esquerda em grupos  
**Textos curtos**: Centro para impacto (ex: estados vazios)

## 4.6 Tratamentos Especiais

### 4.6.1 Ênfase e Destaque

**Negrito (Bold)**
- Usar para: Palavras-chave, termos importantes, avisos
- Peso: Semi Bold (600) ou Bold (700)
- **Exemplo**: "**Importante:** Complete todos os campos"

**Itálico (Italic)**
- Usar para: Citações inline, termos técnicos, ênfase suave
- Peso: Regular (400) em itálico
- **Exemplo**: "_Nota: Esta é uma funcionalidade experimental_"

**Sublinhado (Underline)**
- Usar APENAS para: Links de texto
- Evitar em outros contextos para não confundir com links

**Combinações**
- Bold + Itálico: Para ênfase máxima (usar raramente)
- **_Exemplo extremo de ênfase_**

---

### 4.6.2 Listas

## 4.7 Responsividade Tipográfica

### 4.7.1 Breakpoints

**Mobile Small**: < 375px
- Reduzir H1 para 28px
- Manter demais tamanhos

**Mobile**: 375px - 767px
- Usar escala mobile padrão

**Tablet**: 768px - 1023px
- Usar escala desktop com ajustes
- H1: 40px (intermediário)
- H2: 32px

**Desktop**: 1024px+
- Usar escala desktop completa

**Large Desktop**: 1440px+
- Manter tamanhos desktop
- Aumentar line-height em 10% para conforto

---

### 4.7.2 Fluid Typography (CSS Clamp)

Para transições suaves entre breakpoints:

```css
/* H1 Fluid */
font-size: clamp(32px, 2rem + 2vw, 48px);

/* H2 Fluid */
font-size: clamp(28px, 1.75rem + 1.5vw, 40px);

/* Body Fluid */
font-size: clamp(16px, 1rem + 0.25vw, 18px);
```

## 4.8 Acessibilidade Tipográfica

### 4.8.1 Contraste

✅ **Text Primary sobre Background**: 10.5:1 (AAA)  
✅ **Text Secondary sobre Background**: 7.2:1 (AAA)  
✅ **Text Tertiary sobre Background**: 4.8:1 (AA)  

### 4.8.2 Tamanhos Mínimos

- **Texto normal**: Nunca menor que 14px (0.875rem)
- **Texto em botões**: Mínimo 16px (1rem)
- **Títulos**: Mínimo 18px (1.125rem)

### 4.8.3 Line Height Mínimos

- **Títulos**: Mínimo 1.2x o tamanho da fonte
- **Corpo de texto**: Mínimo 1.5x o tamanho da fonte
- **Textos pequenos**: Mínimo 1.4x o tamanho da fonte

### 4.8.4 Legibilidade

- ✅ Evitar all caps em textos longos
- ✅ Usar sentence case para títulos naturais
- ✅ Evitar linhas muito longas (máx 75 caracteres)
- ✅ Manter espaçamento adequado entre linhas
- ✅ Nunca justificar texto (cria espaçamento irregular)

## 4.9 Implementação

### 4.9.1 Import de Fonte

**Google Fonts CDN**:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

**Self-Hosted** (Recomendado para performance):
```css
@font-face {
  font-family: 'Inter';
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url('/fonts/Inter-Regular.woff2') format('woff2');
}
```
