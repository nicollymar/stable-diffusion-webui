## 🎯 Uso do Manual

### Para Designers
- Consulte as seções 2-5 para especificações visuais
- Use os prompts do Stable Diffusion para gerar assets
- Siga as diretrizes de aplicação da seção 7

### Para Desenvolvedores
- Implemente o Design System da seção 5
- Use os tokens de design das seções 3 e 4
- Siga diretrizes de acessibilidade em todas as seções

### Para Redatores
- Consulte a seção 6 para tom de voz e identidade verbal
- Use o glossário de termos
- Siga os exemplos de microcopy

### Para Marketing
- Use os slogans da seção 6
- Consulte a seção 7 para materiais promocionais
- Siga diretrizes de redes sociais
