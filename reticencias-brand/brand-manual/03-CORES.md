# 3. Sistema de Cores

## 3.1 Filosofia Cromática

O sistema de cores do **reticências** é inspirado em momentos naturais que evocam calma, reflexão e renovação. Cada cor foi cuidadosamente selecionada para transmitir segurança emocional e facilitar estados mentais positivos.

---

## 3.2 Cores Primárias (5 cores principais)

### 3.2.1 Âmbar do Pôr do Sol
**Nome**: Sunset Amber  
**Significado**: Fim de ciclo, aceitação, calor emocional  
**Uso principal**: Botões de ação, destaques importantes, CTAs

**Especificações**:
- **HEX**: `#F4A261`
- **RGB**: 244, 162, 97
- **CMYK**: 0, 34, 60, 4
- **HSL**: 27°, 86%, 67%
- **Pantone**: 1495 C (aproximado)

**Variações de Gradiente**:
1. **Sunset Warm**: `#F4A261` → `#E76F51` (quente intenso)
2. **Sunset Soft**: `#F4A261` → `#F8D5B0` (suave claro)
3. **Sunset Glow**: `#E76F51` → `#F4A261` → `#F8D5B0` (gradiente triplo)

**Acessibilidade**:
- Contraste sobre branco: 3.8:1 (AA para texto grande)
- Contraste sobre #2A4858: 6.2:1 (AAA para texto normal)
- Uso recomendado: Elementos grandes, não para texto pequeno sobre branco

## 3.3 Cores Semânticas

## 3.7 Aplicação das Cores

### 3.7.1 Hierarquia de Uso

**60%** - Cores neutras e fundos (Branco, cinzas claros)  
**30%** - Cor primária principal (Sea Deep para estrutura)  
**10%** - Cores de destaque (Sunset Amber, Sunrise Gold)  

### 3.7.2 Psicologia das Cores no Contexto

**Âmbar/Laranja (Sunset Amber)**
- Evoca: Energia positiva, criatividade, entusiasmo
- Quando usar: Ações afirmativas, conquistas, momentos de celebração
- Evitar em: Conteúdos sobre ansiedade (pode ser muito estimulante)

**Dourado/Amarelo (Sunrise Gold)**
- Evoca: Otimismo, clareza, novo início
- Quando usar: Indicadores de progresso, novos recursos descobertos
- Evitar em: Áreas que requerem calma profunda

**Azul Claro (Sky Calm)**
- Evoca: Tranquilidade, abertura, clareza mental
- Quando usar: Áreas de respiração, exercícios de mindfulness
- Uso versátil em todas as seções

**Azul Escuro (Sea Deep)**
- Evoca: Confiança, profissionalismo, estabilidade
- Quando usar: Estrutura da app, texto principal, navegação
- Base sólida para todo o design

**Verde Claro (Earth Soft)**
- Evoca: Equilíbrio, renovação, harmonia
- Quando usar: Indicadores de conclusão, estatísticas positivas
- Transmite sensação de crescimento
